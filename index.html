BASE TEÓRICA

Fundamento matemático

01 · Recursividad

Una función se define en términos de sí misma y reduce el problema hasta llegar a un caso base. En FORESTGUARD se usa para dibujar ramas, triángulos y subdivisiones.

02 · Recurrencias

Una relación de recurrencia expresa el número de elementos de un nivel a partir de niveles anteriores. Permite estimar el crecimiento del patrón.

03 · Árboles

El árbol de llamadas organiza las invocaciones recursivas en raíz, nodos hijos y hojas. Cada nivel representa una profundidad.

04 · Grafos

La red de sensores es un grafo G = (V, E): los sensores son vértices y las conexiones por proximidad son aristas.

05 · Vecino más cercano

Para un punto P se calcula la distancia euclidiana a cada sensor y se elige el mínimo: d = √((x₂−x₁)² + (y₂−y₁)²).
